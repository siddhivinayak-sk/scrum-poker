{{- if and (gt (int .Values.replicaCount) 1) (ne (.Values.service.sessionAffinity | default "") "ClientIP") }}

WARNING: replicaCount is {{ .Values.replicaCount }} and service.sessionAffinity is not ClientIP.
Poker and retro session state lives in the memory of each pod, so every pod
keeps its own disconnected set of sessions. All participants of one session
need to land on one pod, or they will see different votes and different retro
boards. Set replicaCount to 1, or set service.sessionAffinity to ClientIP.
